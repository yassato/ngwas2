# ngwas2
Neighbor GWAS2: Dissecting oligogenic and polygenic indirect genetic effects through the lens of neighboring plant genotypes

## File description

### coord.R
R function to give x-axis of GWAS Manhattan plots.

### covnei_lmm.R
R function to perform GWAS based on weighted multi-kernel kernels.

### ./simulation
1. x_STVS.vcf.gz  
Genotype data simulated by Sato et al (2023) using SLiMv3 (Haller & Messer 2019), which are available at Dryad (https://doi.org/10.5061/dryad.zs7h44jdv).  

1. simPhenoWithCov.R  
R function to simulate phenotypes with the covariance between DGEs and IGEs.

1. simulations_gp_gwas.R  
R script to perform GP/GWAS simulations

1. simulations_suppl.R  
R script to perform supplementary simulations

### ./apple

1. apple_cov.R  
R script of apple data analyses and visualization

1. REFPOP_Phenotypic_data_3years_non_adjusted_reduced_traits_paper_2_reduced_M1.txt  
Phenotype data downloaded from Data INRAE repository (<https://doi.org/10.15454/VARJYJ>: Jung et al. 2022)

1. ./SNPs_final_2022
- SNPs_final_2022.bed

- SNPs_final_2022.bim

- SNPs_final_2022.fam  
Symbolic links to genotype data. The original data are deposited by Jung et al. (2025) on Zenodo (<https:// doi.org/10.5281/zenodo.14191209>).

### ./aspen

1. aspen2014_cov.R  
R script of aspen data (year 2014) analyses and visualization

1. aspen2015_cov.R  
R script of aspen data (year 2015) analyses and visualization

1. Riehl2023_ece310541-sup-0002-files2_sheet2.csv  
Genotype-phenotype annotation file provided as the supplementary material of Riehl et al. (2023) as the second sheet of "Riehl2023_ece310541-sup-0002-files2.xlsx".  

1. WisAsp_Data2014.csv  
1. WisAsp_Data2015.csv  
Phenotype data downloaded from Dryad (<https://doi.org/10.5061/dryad.st463>: Barker et al. 2018).
 
1. WisAsp.bed
1. WisAsp.bim
1. WisAsp.fam  
Genotype data in a PLINK format downloaded from Dryad (<https://doi.org/10.5061/dryad.fr045hv>: Barker et al. 2019). 


### ./ath

1. calcPVEcov_CHZ.R  
1. calcPVEcov_JPN.R  
Scripts for the reanalysis of the herbivory data on _Arabidopsis thaliana_ in Switzerland (CHZ) and Japan (JPN) (Sato et al. 2024). Input data are available at Zenodo (<https://doi.org/10.5281/zenodo.7945317>).  

### ./grape
1. Flutre2022data
- DLVitis_genotype-identifiers.tsv
- DLVitis_phenotypes.tsv
- snp-chip-gbs-genotypes_concat-fill_beagle_tag-filter-ld9_rm-dup.vcf.gz  
Phenotype, genotype, and their annotation files downloaded from Data INRAE repository (https://doi.org/10.15454/8DHKGL: Flutre 2022)

1. grape_cov.R  
R script of the grape data analyses and visualization

### ./output

_Intermediate files generated by R scripts and used for visualization_

### ./vignette

1. index.html
1. index.Rmd  
Manual of the model implementation in R. The original source file (index.Rmd) and HTML output (index.html)


### ngwas2.Rproj

_RStudio project for this repository_
